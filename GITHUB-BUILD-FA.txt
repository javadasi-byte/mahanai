ساخت خودکار نسخه ویندوز در GitHub

1) در GitHub یک مخزن جدید بسازید و نام آن را MahanAI بگذارید.
2) فایل ZIP پروژه را روی رایانه استخراج کنید.
3) وارد پوشه MahanAI-Windows شوید و همه محتویات آن (از جمله پوشه مخفی .github) را در صفحه مخزن با Add file > Upload files بارگذاری و Commit کنید.
4) در مخزن به تب Actions بروید. گردش کار Build MahanAI for Windows باید دیده شود.
5) پس از پایان موفق، وارد اجرای آخر شوید و از بخش Artifacts فایل MahanAI-Windows-Portable را دانلود کنید.
6) ZIP خروجی را استخراج کنید. پوشه MahanAI شامل MahanAI.exe است.

توجه: این خروجی پوشه Portable است، نه یک EXE تک‌فایلی. برای پاسخ‌گویی واقعی باید llama-server.exe سازگار را در runtime و یک مدل GGUF را در models قرار دهید. این دو فایل در سورس به‌علت حجم/مجوز همراه نیستند.
